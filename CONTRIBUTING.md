# Contributing

Use a focused branch and describe the user-facing problem, change and validation in your pull request.
Run `npm test`, serve the root via HTTP and inspect both demo mode and mobile layout.
Use fictional data. Never commit participant details, credentials or private spreadsheet exports.
Keep the interface in Portuguese; update both READMEs when changing capabilities.
Changes to saved fields need backend compatibility and data dictionary updates.
Map services must retain attribution and respect provider policies.
